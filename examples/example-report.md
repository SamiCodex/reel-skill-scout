# Example report

A real run of the skill on a public Instagram reel, ["10 Fastest Growing Claude Repos"](https://www.instagram.com/reel/DgBVPFEOaA3/) (November 2026). Usefulness ratings are for a content creator, as an example. Star counts are the live totals at the time of the run; the reel itself quoted stars gained that month.
